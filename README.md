# 👁️ Computer Vision Series: From Pixels to AI

### Understanding how machines see the world, one concept at a time. ☕

Welcome to **[Computer-Vision-Series](https://github.com/n7kadda/Computer-Vision-Series)** — a 20-part learning journey through computer vision, from the numerical foundations of images to CNNs, Vision Transformers, object detection, segmentation, tracking, and generative vision.

**The philosophy:** Computer vision explained like we're talking tech over coffee. Expect clear intuition, meaningful technical depth, practical Python experiments, and real-world applications.

## 🚀 Why This Series?

Computer vision powers face authentication, autonomous vehicles, medical image analysis, robotics, visual search, and much more. But how does a machine move from a grid of numbers to recognising objects and interpreting scenes?

We'll build that understanding step by step, explaining **why** each technique exists, **how** it works, and **where** it fits into modern vision systems.

## 💻 Getting Started

Clone the repository:

```bash
git clone https://github.com/n7kadda/Computer-Vision-Series.git
cd Computer-Vision-Series
```

Create and activate a virtual environment:

```bash
python -m venv .venv
source .venv/bin/activate  # macOS/Linux
# On Windows: .venv\Scripts\activate
```

Install the introductory notebook dependencies:

```bash
pip install numpy opencv-python matplotlib jupyter
```

Start Jupyter:

```bash
jupyter notebook
```

> Later notebooks may require additional packages. Check each experiment's instructions before running it.


## 🎯 Who Is This For?

## ☕ How We Learn Here

Every topic aims to answer four questions:

1. **What problem are we trying to solve?**
2. **Why was this technique introduced?**
3. **How does it work under the hood?**
4. **Where would we use it in practice?**

This isn't just a list of algorithms. It's a connected learning path from pixels to visual intelligence.
